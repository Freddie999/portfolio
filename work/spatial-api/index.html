Spatial-data validation API

A reliable boundary for spatial data.

  • Python
  • FastAPI
  • PostGIS

EXPLORE

Source & methods ↗

01 / QUESTION

How can a spatial API reject malformed or ambiguous geometry before it enters a system?

02 / APPROACH

The service validates a bounded 2D WGS84 GeoJSON subset, inserts batches in one transaction, uses GiST-indexed intersection queries, and supports ID-based cursor pagination. Docker packages the local setup.

03 / RESULTS

A runnable service with interactive documentation and 26 tests, including real PostGIS integration checks for atomicity, pagination, and geometry behavior.

04 / MY CONTRIBUTION

Validation, transactional ingestion, spatial queries, demonstration interface, and tests.

05 / WHAT THIS DOES & DOESN’T ESTABLISH

A local engineering demonstration using synthetic survey features. It does not provide authentication, tenant isolation, automatic geometry repair, reprojection, or a deployed public API.
