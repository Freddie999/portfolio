Academic project · Public policy / R

Verifying poverty change in Philadelphia

Reconstructed ACS poverty estimates for 384 census tracts to assess which reported changes can be distinguished from sampling uncertainty.

36 increases · 27 decreases · 313 inconclusive · 8 unassessable. Tract tests use 90% confidence; no multiple-testing correction.

Team academic project · Statistics / R

Explaining Philadelphia housing values

Studied associations between neighborhood characteristics and median house values across 1,720 Philadelphia block groups using 2000 Census data. Combined mapping, regression diagnostics, and five-fold cross-validation.

The four-predictor model reduced held-out RMSE by 17.2% relative to the vacancy-and-income comparison model, measured in log units.

Read the team report ↗ · Source

With Vincent Bio Bediako and Emmanuel Sampson. These are historical associations at block-group level.
