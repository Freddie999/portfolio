01

Mapping / Academic project

When blood takes a shortcut↗

An interactive story about the geography of medical delivery in Rwanda, told through road journeys and drone flight paths.

  • JavaScript
  • Leaflet
  • GeoJSON
Contribution
Narrative, map interactions, route-comparison presentation, and interpretation.
Evidence
A working story map that connects a close-up journey with a wider, screened set of 817 distribution-centre-to-site records.
Scope
Travel times are modeled outbound estimates, not observed complete deliveries. They do not measure lives saved at the mapped facilities. This independent course project relates to my prior work at Zipline.
02

Machine learning / Academic project

Reading the landscape↗

Testing what actually improves a satellite-image classifier: deeper features, augmentation, skip connections, and dropout.

  • Python
  • PyTorch
  • CNN
Contribution
Experimental comparisons, validation-based selection, evaluation, and error analysis.
Evidence
The selected augmented plain CNN classified 3,958 of 4,050 held-out images correctly: 97.73% accuracy and 0.9767 macro F1. Skip connections and dropout did not improve validation accuracy in this run.
Scope
One seed and a random image split. Similar or nearby scenes can cross partitions, so the score does not establish performance in a new region. Adapted from Xiaojiang Li’s course notebook.
03

Engineering / Independent demonstration

Terrain-aware route explorer↗

A linked map and elevation profile for comparing illustrative routes using public terrain data.

  • JavaScript
  • Leaflet
  • Elevation
Contribution
Elevation sampling, calculation helpers, map/profile interface, export, and tests.
Evidence
A working browser demo with local GeoJSON upload, route comparison, and documented calculations. Six tests cover mathematical helpers and data behavior.
Scope
The alignments are illustrative, not verified roads or trails. Terrain pixels are roughly 59 metres wide here. The tool does not optimize routes and is not a navigation or flight-planning system.
